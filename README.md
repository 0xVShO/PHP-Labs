### Як запустити проєкти локально
1) **Клонувати репозиторій**
```bash
git clone https://github.com/0xVShO/PHP-Labs.git
```
2) **Перейти всередину монорепозиторію**
```bash
cd PHP-Labs
```
3) **Виконайте наступну команду Docker**
```bash
docker compose up -d
```
4) **Перейдіть за посиланням типу**
```text
http://localhost:8080/[Назва директорії відповідного практикуму]/
```
